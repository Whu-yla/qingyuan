# 青元剑诀 · 本地完整解锁版

> 本目录是 3D 御剑模拟器《青元剑诀》的离线镜像，完成了「完整解锁」与「去品牌化」改造，并新增了一个塔防模式「剑阵守山」（4 关、4 个 Boss、键鼠与手势双操作）。
> 技术栈：Three.js r128 + MediaPipe HandLandmarker（手势识别）+ 原生 Web Audio。全部资源已本地化，单页应用，双击即玩。

## 一、怎么跑

1. 双击 `启动游戏.command`（第一次可能被 macOS Gatekeeper 拦：右键 → 打开）。
2. 浏览器打开 http://127.0.0.1:8123/index.html ，等加载条走完即进入。
3. 手动起服务（等价）：

   ```bash
   cd qingyuan && python3 -m http.server 8123 --bind 127.0.0.1
   ```

   Windows：`python -m http.server 8123`，然后访问 http://127.0.0.1:8123/ 。
4. 手势控制：点左上"开启手势控制" → 允许摄像头。**必须用 127.0.0.1 或 localhost 访问**（浏览器只在这两种地址下把 http 当安全上下文，局域网 IP 会拿不到摄像头）。
5. 塔防模式：点主界面左下「剑阵守山」，或直接打开 http://127.0.0.1:8123/td/index.html （不需要摄像头也能玩，键鼠操作完整）。

> 别用 `file://` 直接打开 index.html：wasm / 模型 / 音效会被 CORS 拦掉。

### 经济与难度

- 起始灵力 175–215，灵力 = 每秒自然增长（3~3.2）+ 击杀奖励；建塔与施法都消耗灵力。
- 反复用无头浏览器做满编 AI 测试（建满 10 塔并升级 + 完美施法）：4 关均能通关，用时约 1'38" / 1'39" / 2'06" / 2'41"（正常速度），阵眼全满血。
- 若不升级剑阵，第 4 关会被 Boss 突破（阵眼 4/20）——升级是后期关卡的硬需求。
- 真人手速和施法时机弱于脚本，所以当前数值偏宽松；想加难度优先调 `td/levels.js` 里第 3/4 关的敌人血量与 Boss 逃漏惩罚。
